# Project Overview

This is a static website for a paying guest service called "Simple PG Services". It is a single-page website with sections for Home, Room Types, Services, About Us, Gallery, Videos, Reviews, and Contact Us. The website is built using HTML, CSS, and JavaScript.

# Key Files

- `home.html`: The main entry point of the website. It contains the entire content of the single-page website.
- `css/styles.css`: The main stylesheet for the website.
- `scripts/`: This directory contains the JavaScript files for the website.
    - `slide_show.js`: Implements an image slideshow.
    - `change_about_us_img.js`: Dynamically changes images in the "About Us" section.
    - `change_contact_dyn.js`: Dynamically changes contact information.
    - `nav_bar.js`: Implements the navigation bar functionality.

# Building and Running

This is a static website, so there is no build process. To run the website, simply open the `home.html` file in a web browser.

# Development Conventions

The JavaScript code is written in a procedural style and does not use any modern frameworks. The code is well-commented and easy to understand.
